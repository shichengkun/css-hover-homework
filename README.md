# HTML + CSS 图形悬停作业

打开 `index.html` 即可查看六个渐变图形，无需安装依赖。

## 作业效果

- 六个图形：方形、两种圆角方形、橙黄色圆形、青绿色圆角方形、紫色圆形。
- 鼠标悬停时，`transform: translateY(-10px)` 使图形上移 10 像素。
- `box-shadow: 0 0 20px ...` 将阴影的水平、垂直偏移量变为 0。
- 使用 `::after` 伪元素在图形中心显示 `hover`。
- 使用 `transition` 实现平滑变化，小屏幕下自动换行。

沿用课堂示例的 `.stage` 容器和 `.cube` 图形结构，全部效果由 HTML 和 CSS 实现。

## 手动检查

1. 双击 `index.html`，确认六个图形正常显示。
2. 将鼠标依次移入六个图形，确认上移、阴影和文字变化。
3. 移出鼠标，确认恢复原样。
4. 缩小浏览器窗口，确认图形自动换行。
